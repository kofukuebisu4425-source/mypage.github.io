制作したプロジェクト

Java Music Player

学校のチーム開発でJavaを使用した音楽プレーヤーを制作しました。 ユーザーが歌手や曲を選択するとMP3ファイルを再生できるシステムです。

使用技術

  • Java
  • JLayer (MP3再生ライブラリ)
  • Scanner
  • FileInputStream

工夫した点

ユーザーが選択した曲を再生できるようにし、 次の曲を自動再生する機能やメニュー画面を作成しました。 チームメンバーと協力しながら開発を進めました。
